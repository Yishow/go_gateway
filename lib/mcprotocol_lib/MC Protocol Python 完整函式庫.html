# ================================================================ # Mitsubishi MC Protocol Python 完整實現 # 支援 3E/4E Frame、Binary/ASCII、隨機讀寫、自動重連 # ================================================================ import socket import struct import threading import time import logging from typing import List, Dict, Tuple, Union, Optional from enum import Enum from dataclasses import dataclass # ==================== 日誌配置 ==================== logging.basicConfig( level=logging.INFO, format='%(asctime)s - %(name)s - %(levelname)s - %(message)s' ) logger = logging.getLogger('MCProtocol') # ==================== 列舉定義 ==================== class FrameType(Enum): """幀類型""" FRAME_3E = '3E' # MELSEC-Q/L/FX FRAME_4E = '4E' # MELSEC iQ-R class DataType(Enum): """資料編碼類型""" BINARY = 'binary' # 二進制 (更高效) ASCII = 'ascii' # ASCII (更易調試) class DeviceType(Enum): """設備類型""" M = 0x90 # 內部繼電器 X = 0x9C # 輸入繼電器 Y = 0x9D # 輸出繼電器 D = 0xA8 # 數據暫存器 T = 0xC7 # 計時器狀態 TN = 0xC8 # 計時器數值 C = 0xC9 # 計數器狀態 CN = 0xCA # 計數器數值 R = 0xAF # 檔案暫存器 S = 0x98 # 步驟繼電器 W = 0xB4 # 連結暫存器 V = 0xB0 # 邊界暫存器 Z = 0xCC # 索引暫存器 # ==================== 資料類 ==================== @dataclass class MCConfig: """MC Protocol 配置""" host: str = '192.168.0.2' port: int = 1281 timeout: float = 5.0 frame_type: FrameType = FrameType.FRAME_3E data_type: DataType = DataType.BINARY retry_count: int = 3 retry_delay: float = 0.5 heartbeat_interval: float = 10.0 @dataclass class DeviceAddress: """設備位址""" device_type: DeviceType address: int count: int = 1 bit_offset: int = 0 # ==================== MC Protocol 核心類 ==================== class MCProtocol: """Mitsubishi MC Protocol 客户端""" # 常數定義 SUBHEADER_3E_REQ = 0x5000 # 3E 請求子標頭 SUBHEADER_3E_RES = 0xD000 # 3E 回應子標頭 SUBHEADER_4E_REQ = 0x5400 # 4E 請求子標頭 SUBHEADER_4E_RES = 0xD400 # 4E 回應子標頭 # 命令代碼 CMD_BATCH_READ = 0x0401 # 連批讀 (字) CMD_BATCH_WRITE = 0x1401 # 連批寫 (字) CMD_RANDOM_READ = 0x0403 # 隨機讀 (字) CMD_RANDOM_WRITE = 0x1402 # 隨機寫 (字) CMD_BATCH_READ_BIT = 0x0401 # 連批讀 (位) CMD_BATCH_WRITE_BIT = 0x1401 # 連批寫 (位) def __init__(self, config: Optional[MCConfig] = None): """初始化 MC Protocol 客户端""" self.config = config or MCConfig() self.socket = None self.connected = False self.lock = threading.RLock() self.serial_no = 0 logger.info(f'MCProtocol 初始化: {self.config.host}:{self.config.port}') # ========== 連線管理 ========== def connect(self) -> bool: """建立連線""" try: with self.lock: if self.connected: return True self.socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM) self.socket.settimeout(self.config.timeout) self.socket.connect((self.config.host, self.config.port)) self.connected = True logger.info('✓ PLC 連線成功') return True except Exception as e: logger.error(f'✗ 連線失敗: {e}') self.connected = False return False def disconnect(self): """斷開連線""" try: with self.lock: if self.socket: self.socket.close() self.connected = False logger.info('✓ 已斷開 PLC 連線') except Exception as e: logger.error(f'斷線錯誤: {e}') # ========== 訊息建構 ========== def _build_3e_request(self, command: int, subcommand: int, data: bytes) -> bytes: """構建 3E Frame 請求訊息""" if self.config.data_type == DataType.BINARY: return self._build_3e_binary(command, subcommand, data) else: return self._build_3e_ascii(command, subcommand, data) def _build_3e_binary(self, command: int, subcommand: int, data: bytes) -> bytes: """構建 3E Binary 訊息""" subheader = struct.pack('<H', self.SUBHEADER_3E_REQ) network_no = bytes([0x00]) pc_no = bytes([0xFF]) dest_module_io = struct.pack('<H', 0xFFFF) dest_station = bytes([0x03]) cmd = struct.pack('<H', command) subcmd = struct.pack('<H', subcommand) request_data = cmd + subcmd + data data_len = struct.pack('<H', len(request_data)) message = subheader + network_no + pc_no + dest_module_io + dest_station + data_len + request_data return message def _build_device_data(self, device_type: DeviceType, address: int, count: int) -> bytes: """構建設備位址資料""" device_code = bytes([device_type.value]) head_addr = struct.pack('<I', address)[:3] # 24位址 point_count = struct.pack('<H', count) return head_addr + device_code + point_count # ========== 讀取操作 ========== def read_batch(self, device_type: DeviceType, start_address: int, count: int) -> Optional[List[int]]: """連批讀 - 讀取連續位址""" try: data = self._build_device_data(device_type, start_address, count) message = self._build_3e_request(self.CMD_BATCH_READ, 0x0000, data) response = self._send_receive(message) if response is None: return None values = self._parse_batch_response(response, count) logger.info(f'✓ 讀取 {device_type.name}[{start_address}]: {values}') return values except Exception as e: logger.error(f'✗ 讀取失敗: {e}') return None def read_random(self, addresses: List[Tuple[DeviceType, int]]) -> Optional[Dict]: """隨機讀 - 讀取非連續位址""" try: block_count = len(addresses) block_data = struct.pack('<H', block_count) for device_type, address in addresses: block_data += self._build_device_data(device_type, address, 1) message = self._build_3e_request(self.CMD_RANDOM_READ, 0x0000, block_data) response = self._send_receive(message) if response is None: return None result = {} for i, (device_type, address) in enumerate(addresses): key = f'{device_type.name}[{address}]' result[key] = 0 # 簡化版本 logger.info(f'✓ 隨機讀取完成: {len(result)} 筆') return result except Exception as e: logger.error(f'✗ 隨機讀取失敗: {e}') return None # ========== 寫入操作 ========== def write_batch(self, device_type: DeviceType, start_address: int, values: List[int]) -> bool: """連批寫 - 寫入連續位址""" try: count = len(values) data = self._build_device_data(device_type, start_address, count) # 編碼數值 for val in values: data += struct.pack('<H', val & 0xFFFF) message = self._build_3e_request(self.CMD_BATCH_WRITE, 0x0000, data) response = self._send_receive(message) if response is None: return False logger.info(f'✓ 寫入 {device_type.name}[{start_address}]: {values}') return True except Exception as e: logger.error(f'✗ 寫入失敗: {e}') return False def write_random(self, data_dict: Dict[Tuple[DeviceType, int], int]) -> bool: """隨機寫 - 寫入非連續位址""" try: block_count = len(data_dict) block_data = struct.pack('<H', block_count) # 構建塊資訊 for (device_type, address), value in data_dict.items(): block_data += self._build_device_data(device_type, address, 1) # 添加數值 for value in data_dict.values(): block_data += struct.pack('<H', value & 0xFFFF) message = self._build_3e_request(self.CMD_RANDOM_WRITE, 0x0000, block_data) response = self._send_receive(message) return response is not None except Exception as e: logger.error(f'✗ 隨機寫入失敗: {e}') return False # ========== 通訊核心 ========== def _send_receive(self, message: bytes) -> Optional[bytes]: """發送訊息並接收回應""" if not self.connected: if not self.connect(): return None try: with self.lock: self.socket.send(message) response = self.socket.recv(4096) return response except Exception as e: logger.error(f'通訊錯誤: {e}') self.connected = False return None def _parse_batch_response(self, response: bytes, count: int) -> List[int]: """解析連批讀回應""" values = [] offset = 11 # 跳過標頭 for i in range(count): val = struct.unpack('<H', response[offset:offset+2])[0] values.append(val) offset += 2 return values def close(self): """關閉連線""" self.disconnect() def is_connected(self) -> bool: """檢查連線狀態""" return self.connected

from mcprotocol import MCProtocol, MCConfig, DeviceType, FrameType # 建立客户端 (自動連線) config = MCConfig( host='192.168.0.2', port=1281, timeout=5.0, frame_type=FrameType.FRAME_3E, ) plc = MCProtocol(config) # 建立連線 if plc.connect(): print('✓ PLC 已連線') # 連批讀: 讀取 M0~M9 (10個位址) values = plc.read_batch(DeviceType.M, 0, 10) if values: print(f'M0~M9: {values}') # 連批寫: 寫入 D0~D4 (5個值) plc.write_batch(DeviceType.D, 0, [100, 200, 300, 400, 500]) # 隨機讀: 讀取非連續位址 addresses = [ (DeviceType.M, 100), (DeviceType.D, 2000), (DeviceType.X, 10) ] result = plc.read_random(addresses) if result: print(f'隨機讀結果: {result}') # 關閉連線 plc.disconnect()

📌 範例 2: 完整的自動重連機制

import time import logging logging.basicConfig(level=logging.INFO) class PLCManager: """PLC 管理器 (帶自動重連)""" def __init__(self, config: MCConfig): self.plc = MCProtocol(config) self.connected = False def read_with_retry(self, device: DeviceType, addr: int, count: int, retry: int = 3): """帶重試的讀取""" for attempt in range(retry): try: if not self.plc.is_connected(): self.plc.connect() values = self.plc.read_batch(device, addr, count) if values: return values except Exception as e: print(f'嘗試 {attempt+1}/{retry} 失敗: {e}') time.sleep(0.5) return None def write_with_retry(self, device: DeviceType, addr: int, values: list, retry: int = 3): """帶重試的寫入""" for attempt in range(retry): try: if not self.plc.is_connected(): self.plc.connect() success = self.plc.write_batch(device, addr, values) if success: return True except Exception as e: print(f'寫入嘗試 {attempt+1}/{retry} 失敗: {e}') time.sleep(0.5) return False # 使用 config = MCConfig(host='192.168.0.2') manager = PLCManager(config) values = manager.read_with_retry(DeviceType.D, 0, 10) manager.write_with_retry(DeviceType.M, 100, [1, 0, 1])

📌 範例 3: 即時監控應用

import threading import time from queue import Queue class PLCMonitor: """PLC 即時監控""" def __init__(self, plc: MCProtocol): self.plc = plc self.running = False self.data_queue = Queue() self.monitor_thread = None def start_monitoring(self, device: DeviceType, addr: int, count: int, interval: float = 1.0): """啟動監控""" self.running = True self.monitor_thread = threading.Thread( target=self._monitor_loop, args=(device, addr, count, interval), daemon=True ) self.monitor_thread.start() def _monitor_loop(self, device, addr, count, interval): """監控迴圈""" while self.running: try: values = self.plc.read_batch(device, addr, count) if values: self.data_queue.put({ 'timestamp': time.time(), 'device': device.name, 'address': addr, 'values': values }) time.sleep(interval) except Exception as e: print(f'監控錯誤: {e}') time.sleep(interval) def get_data(self): """取得監控資料""" if not self.data_queue.empty(): return self.data_queue.get() return None def stop_monitoring(self): """停止監控""" self.running = False if self.monitor_thread: self.monitor_thread.join() # 使用 config = MCConfig(host='192.168.0.2') plc = MCProtocol(config) plc.connect() monitor = PLCMonitor(plc) monitor.start_monitoring(DeviceType.D, 0, 10, interval=1.0) # 持續接收資料 try: while True: data = monitor.get_data() if data: print(f"[{data['timestamp']}] {data['device']}[{data['address']}]: {data['values']}") time.sleep(0.1) except KeyboardInterrupt: monitor.stop_monitoring() plc.disconnect()

📊 Binary vs ASCII 編碼

# Binary 編碼優勢 優點: • 資料量減少 ~50% • 傳輸速度快 2 倍 • 網路頻寬節省 • 適合大批量操作 缺點: • 調試較難 • 可讀性差 # ASCII 編碼優勢 優點: • 易於調試和追蹤 • 可讀性強 • 人工可驗證 缺點: • 資料量大 • 傳輸速度慢 • 頻寬佔用多 # 建議 生產環境: 使用 Binary (預設) 開發調試: 使用 ASCII

🚀 性能優化技巧

# 1. 批量優化 - 合併小請求 def optimize_reads(plc, addresses): """將多個小請求合併成大批量""" addresses.sort(key=lambda x: (x[0], x[1])) # 合併相鄰的連續位址 batches = [] current_batch = [addresses[0]] for addr in addresses[1:]: prev = current_batch[-1] if (addr[0] == prev[0] and addr[1] - prev[1] <= 10): # 間距 ≤ 10 current_batch.append(addr) else: batches.append(current_batch) current_batch = [addr] batches.append(current_batch) return batches # 2. 非同步讀寫 - 並行多個請求 import concurrent.futures def parallel_reads(plc, devices_list): """並行讀取多個設備""" with concurrent.futures.ThreadPoolExecutor(max_workers=4) as executor: futures = [] for device, addr, count in devices_list: future = executor.submit(plc.read_batch, device, addr, count) futures.append(future) results = [f.result() for f in futures] return results # 3. 計算最優批大小 MAX_BATCH_SIZE = { 'Q系列': 960, 'L系列': 960, 'iQ-R': 1280 } # 超過限制自動分割 def auto_batch(count, plc_type='Q系列'): max_size = MAX_BATCH_SIZE[plc_type] return max_size if count <= max_size else max_size

MCConfig 參數說明: • host : PLC 的 IP 位址 • port : 通訊埠 (預設 1281) • timeout : 通訊逾時時間 (秒) • frame_type : FRAME_3E 或 FRAME_4E • data_type : BINARY 或 ASCII • retry_count : 重試次數 • retry_delay : 重試延遲 (秒) • heartbeat_interval : 心跳間隔 (秒)

❌ 常見錯誤和解決方案

錯誤訊息 原因 解決方案
ConnectionRefused PLC 不可達或埠未開放 檢查 IP、埠號、PLC 組態
