## 11.0 側邊欄測試工具強化（Sidebar Test UI）
本階段目標為補強 `web/test-ui` 的 Sidebar 測試工具能力，對齊 `debug_roadmap.md` 之規劃。

*   **11.1 現況盤點與資料模型對齊**
    *   11.1.1 盤點現有 Test UI 卡片、Profile 與儲存位置（localStorage）。
    *   11.1.2 定義 Template / History / Compare / Analyzer 的核心資料結構（與 Profile 相容）。
    *   11.1.3 補齊資料遷移策略（Profile -> Template）。
*   **11.2 模板管理（Template Management）**
    *   11.2.1 Template CRUD（建立、編輯、刪除、列表）。
    *   11.2.2 模板分類與標籤（協議、用途、設備類型）。
    *   11.2.3 模板匯入/匯出（JSON + 驗證）。
    *   11.2.4 模板變數替換（${IP}, ${PORT} 等）與欄位校驗。
    *   11.2.5 模板版本管理（歷史、回退）。
    *   11.2.6 收藏與最近使用清單。
*   **11.3 測試歷史（History）**
    *   11.3.1 定義統一事件格式與結果結構。
    *   11.3.2 在測試操作、監控、掃描、RTU Polling 掛鉤記錄。
    *   11.3.3 IndexedDB 儲存與索引策略（時間、協議、結果）。
    *   11.3.4 列表檢視（篩選、搜尋、分頁/虛擬滾動）。
    *   11.3.5 詳情面板（參數、結果、錯誤、耗時）。
    *   11.3.6 統計視圖（成功率、延遲、類型分布）。
    *   11.3.7 匯出與清理機制（CSV/JSON、保留期限）。
*   **11.4 對比模式（Compare Mode）**
    *   11.4.1 多連線管理（連線上限、命名、狀態卡）。
    *   11.4.2 同步操作執行與結果收集。
    *   11.4.3 差異高亮與對比表格。
    *   11.4.4 對比圖表與趨勢視覺化。
    *   11.4.5 對比報告生成與匯出。
*   **11.5 協議分析器（Protocol Analyzer）**
    *   11.5.1 封包捕獲控制與狀態管理。
    *   11.5.2 封包解析（Modbus/Fatek/MC）。
    *   11.5.3 檢視與過濾（協議/地址/類型/關鍵字）。
    *   11.5.4 通訊時序與統計圖表。
    *   11.5.5 性能分析與異常偵測。
    *   11.5.6 報告生成（HTML/PDF）。
*   **11.6 技術風險與基礎建設**
    *   11.6.1 IndexedDB 封裝與資料遷移工具。
    *   11.6.2 狀態管理引入（Zustand/Redux）與模組化。
    *   11.6.3 大量資料效能（虛擬列表、分頁）。
    *   11.6.4 後端支援介面（封包捕獲 API、分析 API）。
