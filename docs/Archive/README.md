# docs/Archive

此目錄存放已過時或已被取代的歷史文件（2026-10-01 整理）。歸檔原則：

- 內容描述的是已完成或已放棄的階段性規劃（WBS、roadmap、redesign、session 計畫、一次性分析報告）。
- 與現行架構牴觸：legacy `/studio`、舊 workbench、superpowers/specs 時期的設計；現行契約以 `docs/technical/studio-surface-inventory/`、`docs/plans/` 與 source 為準。
- 一次性 prompt 模板（templates/）與舊設計流程文件。

## 內容對照

| `docs/*.md`、`docs/*.html`（2026-01～2026-03 頂層文件） | 規劃、WBS、分析報告、除錯 roadmap、build/啟動說明、工作流程與驗收清單 |

## 使用注意

- 歸檔文件不反映現況，不可作為完成證據或現行規格引用。
- 未歸檔的現行文件：`docs/technical/`、`docs/plans/`、`docs/releases/`、`docs/swagger/`、`docs/goal.md`、`docs/ENV_CONFIG.md`、`docs/process/model-switch-playbook.md`。
- `openspec/specs/` 與 `openspec/changes/archive/` 內以原路徑記錄的 provenance 清單（如 `docs/superpowers/...`）對應本目錄下同名檔案；這些清單保留歸檔當時的原始路徑，不追溯改寫。
