## 0. 專案現況分析與補強方向

### 0.1 現況盤點（test-ui）

- 前端位於 `web/test-ui`，採 React + TypeScript，卡片化 UI 已完成（測試操作、監控、掃描、RTU Polling、調試面板）。
- 已有 Profile 管理（`useProfiles` + localStorage），並在 `TestPage` 自動保存連線配置。
- Profile 結構包含 `protocol` / `connectionMode` / `config` / `monitorConfig`，可作為模板系統的最小可用資料模型。

### 0.2 差距與風險

- 目前僅有 Profile 的單層保存，缺乏模板分類/版本/變數/分享等管理能力。
- 尚未建立測試歷史的持久化事件記錄與查詢索引。
- 無多連線對比或協議分析器的資料流與 API 支援。
- 大量資料（歷史/封包）不適合 localStorage，需要 IndexedDB 與分頁/虛擬列表。

### 0.3 補強策略

- 模板管理以現有 Profile 為基礎擴充欄位，提供向後相容的遷移路徑。
- 歷史記錄建立統一事件格式，從既有操作元件掛鉤採集，避免重複改造。
- 對比模式與協議分析器先定義資料流與 API，再逐步實作 UI。

## 2. 模板管理

**狀態**: 🚧 待開發

**功能概述**: 將常用測試配置保存為可重複使用的模板，提升測試效率。

### 2.1 核心功能

#### 2.1.1 模板庫管理

**功能描述**: 提供完整的模板 CRUD 操作與組織管理。

**詳細需求**:

- **模板創建**
  - 從當前測試配置創建模板
  - 手動創建空白模板
  - 模板命名與描述
  - 模板圖標選擇（可選）

- **模板編輯**
  - 修改模板配置
  - 更新模板描述
  - 調整模板分類

- **模板刪除**
  - 單個刪除（含確認對話框）
  - 批量刪除
  - 刪除前檢查使用情況

- **模板分類**
  - 按協議分類（Modbus、Fatek、MC Protocol）
  - 按用途分類（生產測試、開發測試、故障診斷）
  - 按設備類型分類（PLC、變頻器、儀表）
  - 自定義分類標籤

- **模板搜尋**
  - 關鍵字搜尋（名稱、描述）
  - 標籤篩選
  - 協議類型篩選
  - 組合篩選

- **模板匯入/匯出**
  - 匯出為 JSON 格式
  - 匯入 JSON 模板文件
  - 批量匯入
  - 匯入驗證（格式檢查、衝突處理）

#### 2.1.2 模板內容

**功能描述**: 定義模板可保存的配置內容。

**詳細需求**:

- **連線配置**
  - 協議類型（modbus_tcp、fatek_serial 等）
  - 連線模式（TCP、UDP、Serial）
  - 連線參數（主機、埠號、串列埠設定等）
  - 站號/單元 ID

- **操作序列**
  - 保存常用讀寫操作序列
  - 操作順序定義
  - 操作參數（地址、數量、值）
  - 操作間延遲設定（可選）

- **監控配置**
  - 監控項目列表
  - 監控間隔
  - 監控項目標籤與說明

- **模板預覽**
  - 配置摘要顯示
  - 協議與模式標識
  - 操作數量統計
  - 最後更新時間

#### 2.1.3 快速應用

**功能描述**: 提供便捷的模板載入與應用機制。

**詳細需求**:

- **一鍵載入**
  - 從模板庫選擇模板
  - 自動填充測試工具配置
  - 載入操作序列（可選）
  - 載入監控配置（可選）

- **模板變數替換**
  - 支援變數定義（如 `${IP}`、`${PORT}`、`${STATION_ID}`）
  - 載入時提示輸入變數值
  - 變數驗證（格式、範圍檢查）
  - 預設值設定

- **模板收藏**
  - 標記常用模板
  - 收藏列表快速訪問
  - 收藏模板置頂顯示

- **快速入口**
  - Sidebar 顯示最近使用的模板
  - 快捷鍵支援（可選）
  - 模板使用統計

### 2.2 進階功能

- **模板版本管理**
  - 模板版本歷史
  - 版本比較
  - 版本回退
  - 版本標記（正式版、測試版）

- **模板分享**
  - 生成分享碼（加密）
  - 分享碼匯入
  - 分享權限控制（只讀、可編輯）

- **模板市場**
  - 預設模板庫（內建常用配置）
  - 社群模板（未來擴展）
  - 模板評分與評論（未來擴展）

- **模板驗證**
  - 配置有效性檢查
  - 參數範圍驗證
  - 協議兼容性檢查
  - 驗證報告生成

### 2.3 技術實現要點

- **數據存儲**: LocalStorage 或 IndexedDB
- **數據結構**: JSON 格式，與 Profile 結構兼容
- **UI 組件**: 模板列表、模板編輯器、模板預覽卡片
- **API 整合**: 與現有 Profile 系統整合

## 3. 測試歷史

**狀態**: 🚧 待開發

**功能概述**: 記錄與追蹤所有測試操作，便於分析與回溯。

### 3.1 核心功能

#### 3.1.1 歷史記錄列表

**功能描述**: 提供完整的歷史記錄瀏覽與管理介面。

**詳細需求**:

- **時間軸視圖**
  - 按時間倒序排列（最新在前）
  - 時間分組（今天、昨天、本週、本月、更早）
  - 時間軸視覺化（可選）
  - 時間範圍選擇器

- **篩選功能**
  - 按協議篩選（Modbus、Fatek、MC Protocol）
  - 按操作類型篩選（讀、寫、連線、斷線、掃描）
  - 按時間範圍篩選（自定義日期範圍）
  - 按連線 ID 篩選
  - 按結果狀態篩選（成功、失敗、超時）
  - 組合篩選（多條件 AND/OR）

- **搜尋功能**
  - 關鍵字搜尋（操作參數、錯誤訊息）
  - 標籤搜尋
  - 高級搜尋（正則表達式支援，可選）
  - 搜尋歷史記錄

- **分頁與排序**
  - 分頁顯示（每頁 20/50/100 條）
  - 排序選項（時間、協議、操作類型、結果）
  - 虛擬滾動（優化大量數據性能）

#### 3.1.2 記錄詳情

**功能描述**: 顯示單條歷史記錄的完整資訊。

**詳細需求**:

- **操作資訊**
  - 操作類型（讀/寫/連線/斷線/掃描/監控）
  - 操作時間戳（精確到毫秒）
  - 操作持續時間（如適用）

- **操作參數**
  - 協議類型
  - 連線配置（主機、埠號等）
  - 操作地址
  - 操作數量/值
  - 協議特定參數（symbol、device、unit_id 等）

- **操作結果**
  - 成功/失敗狀態
  - 返回值（讀操作）
  - 錯誤訊息（失敗時）
  - 響應時間
  - 數據大小（位元組數）

- **上下文資訊**
  - 連線 ID
  - 連線狀態快照
  - 操作前後狀態對比（可選）
  - 相關操作鏈（可選）

#### 3.1.3 統計分析

**功能描述**: 提供歷史數據的統計與分析功能。

**詳細需求**:

- **操作統計**
  - 總操作次數
  - 成功/失敗次數與比例
  - 平均響應時間
  - 最大/最小響應時間
  - 操作類型分布（餅圖、柱狀圖）

- **錯誤分析**
  - 錯誤類型分布
  - 錯誤頻率統計
  - 錯誤時間趨勢
  - 常見錯誤模式識別

- **時間趨勢圖**
  - 操作頻率趨勢（折線圖）
  - 錯誤率趨勢
  - 響應時間趨勢
  - 可選時間粒度（小時、天、週）

- **協議使用統計**
  - 各協議使用次數
  - 各協議成功率
  - 各協議平均響應時間
  - 協議使用趨勢

#### 3.1.4 記錄管理

**功能描述**: 提供記錄的匯出、刪除與標記功能。

**詳細需求**:

- **匯出功能**
  - 匯出為 CSV（Excel 兼容）
  - 匯出為 JSON
  - 匯出為 Excel（.xlsx，可選）
  - 自定義匯出欄位
  - 匯出篩選後的記錄

- **批量操作**
  - 批量刪除（含確認）
  - 批量標記
  - 批量匯出

- **記錄標記**
  - 添加自定義標籤
  - 標記為重要
  - 標記為異常
  - 添加註解/備註

- **自動清理**
  - 設定保留期限（天數）
  - 自動刪除過期記錄
  - 清理策略設定（按時間、按數量）
  - 清理前備份（可選）

### 3.2 進階功能

- **記錄回放**
  - 選擇歷史操作序列
  - 一鍵重現操作
  - 回放速度控制
  - 回放結果對比

- **記錄對比**
  - 選擇多條記錄進行對比
  - 並排顯示對比結果
  - 差異高亮顯示
  - 對比報告生成

- **異常檢測**
  - 自動標記異常操作（響應時間過長、錯誤率過高）
  - 異常模式識別
  - 異常告警（可選）

- **記錄關聯**
  - 追蹤相關操作鏈（同一連線的操作序列）
  - 操作依賴關係視覺化
  - 影響範圍分析

### 3.3 技術實現要點

- **數據存儲**: IndexedDB（支援大量數據與複雜查詢）
- **數據結構**: 統一的歷史記錄格式
- **性能優化**: 虛擬滾動、數據分頁、索引優化
- **UI 組件**: 記錄列表、詳情面板、統計圖表、篩選器

## 4. 對比模式

**狀態**: 🚧 待開發

**功能概述**: 同時測試多個設備或配置，進行對比分析。

### 4.1 核心功能

#### 4.1.1 多連線管理

**功能描述**: 管理多個並行的測試連線。

**詳細需求**:

- **連線創建**
  - 創建多個連線（最多支援 4-8 個，可配置）
  - 每個連線獨立配置（協議、主機、埠號等）
  - 連線命名與顏色標識
  - 連線分組（可選）

- **連線狀態總覽**
  - 所有連線狀態一覽表（卡片視圖）
  - 連線狀態指示器（已連線/未連線/錯誤）
  - 快速連線/斷線操作
  - 連線健康度監控

- **連線切換**
  - 快速切換當前操作的連線
  - 連線標籤頁（Tab 視圖，可選）
  - 連線快捷鍵（可選）

#### 4.1.2 同步操作

**功能描述**: 對多個連線執行相同的操作並對比結果。

**詳細需求**:

- **同步執行**
  - 選擇目標連線（可多選）
  - 定義操作（讀/寫）
  - 同步執行操作
  - 執行進度顯示

- **結果顯示**
  - 並排顯示各連線結果
  - 結果表格視圖
  - 結果卡片視圖
  - 結果 JSON 視圖（可選）

- **差異高亮**
  - 自動標示不同結果
  - 差異值計算（數值差異、百分比）
  - 差異顏色標識（可配置）
  - 差異統計（有多少連線結果不同）

- **結果對比表格**
  - 表格列：連線名稱、操作結果、差異標記
  - 排序功能（按結果值、按差異）
  - 匯出對比結果

#### 4.1.3 對比視圖

**功能描述**: 提供多種視覺化方式展示對比數據。

**詳細需求**:

- **並排監控**
  - 多個連線的監控數據並排顯示
  - 實時更新
  - 同步時間軸

- **對比圖表**
  - 折線圖：多條線對比數據趨勢
  - 柱狀圖：對比特定時間點的數據
  - 散點圖：對比數據分布（可選）
  - 圖表互動（縮放、平移、圖例切換）

- **差異統計**
  - 數值差異統計（最大、最小、平均差異）
  - 百分比差異
  - 差異分布圖
  - 一致性指標（所有連線結果相同的比例）

- **自定義對比指標**
  - 定義對比計算公式
  - 自定義差異閾值
  - 告警規則（差異超過閾值時提醒）

#### 4.1.4 對比分析

**功能描述**: 提供深度的對比分析功能。

**詳細需求**:

- **數據一致性檢查**
  - 自動檢測數據不一致
  - 不一致項目列表
  - 不一致程度評級

- **響應時間對比**
  - 各連線響應時間對比
  - 響應時間分布圖
  - 性能排名

- **錯誤率對比**
  - 各連線錯誤次數統計
  - 錯誤率對比圖
  - 錯誤類型分布對比

- **對比報告生成**
  - 自動生成對比報告
  - 報告包含：對比摘要、詳細數據、圖表、結論
  - 報告格式：HTML、PDF（可選）

### 4.2 進階功能

- **對比模板**
  - 保存常用對比配置
  - 快速載入對比模板
  - 模板變數替換

- **自動化對比測試**
  - 定時執行對比操作
  - 對比結果自動記錄
  - 異常自動告警

- **對比結果匯出**
  - 匯出對比報告
  - 匯出對比數據（CSV、JSON）
  - 匯出對比圖表（PNG、SVG）

- **多設備壓力測試對比**
  - 同時對多個設備進行壓力測試
  - 對比各設備的負載表現
  - 性能瓶頸識別

### 4.3 技術實現要點

- **狀態管理**: 管理多個連線狀態（Redux/Zustand）
- **並發控制**: 同步操作的並發執行與結果收集
- **UI 布局**: 響應式布局，支援多列並排顯示
- **圖表庫**: 使用 Chart.js 或 Recharts 實現對比圖表

## 5. 協議分析器

**狀態**: 🚧 待開發

**功能概述**: 深入分析協議通訊細節，診斷問題與優化性能。

### 5.1 核心功能

#### 5.1.1 封包捕獲與分析

**功能描述**: 捕獲並分析通訊封包。

**詳細需求**:

- **實時捕獲**
  - 啟動/停止捕獲
  - 捕獲所有通過系統的通訊封包
  - 捕獲統計（封包數量、數據量、速率）

- **封包解析**
  - 協議層級解析（應用層、傳輸層）
  - 欄位解析（功能碼、地址、數據等）
  - 十六進制視圖
  - ASCII 視圖（如適用）

- **封包過濾**
  - 按協議類型過濾
  - 按地址範圍過濾
  - 按操作類型過濾（讀/寫）
  - 按連線 ID 過濾
  - 自定義過濾規則（正則表達式，可選）

- **封包搜尋與標記**
  - 關鍵字搜尋
  - 標記重要封包
  - 標記異常封包
  - 搜尋結果高亮

#### 5.1.2 協議解析

**功能描述**: 提供多協議的詳細解析。

**詳細需求**:

- **多協議支援**
  - Modbus TCP/RTU 解析
  - Fatek 協議解析
  - MC Protocol 解析
  - 協議自動識別

- **封包結構視覺化**
  - 樹狀結構視圖（展開/折疊）
  - 欄位高亮顯示
  - 欄位值說明
  - 原始十六進制對照

- **欄位說明**
  - 每個欄位的協議規範說明
  - 欄位取值範圍
  - 欄位用途說明
  - 相關協議文檔連結（可選）

- **自動識別**
  - 根據封包格式自動識別協議類型
  - 識別協議版本（如適用）
  - 識別操作類型

#### 5.1.3 通訊分析

**功能描述**: 分析通訊模式與統計。

**詳細需求**:

- **通訊時序圖**
  - 請求/響應時間線視覺化
  - 顯示請求發送時間與響應接收時間
  - 顯示通訊延遲
  - 互動式時間軸（縮放、平移）

- **通訊統計**
  - 封包數量統計（總數、請求數、響應數）
  - 封包大小統計（平均、最大、最小）
  - 通訊頻率統計（每秒封包數）
  - 數據流量統計（位元組/秒）

- **錯誤封包分析**
  - CRC 錯誤檢測
  - 超時錯誤標記
  - 格式錯誤標記
  - 協議違規檢測
  - 錯誤統計與分類

- **通訊模式識別**
  - 輪詢模式識別（定時輪詢）
  - 事件驅動模式識別
  - 批量操作模式識別
  - 模式統計與分析

#### 5.1.4 性能分析

**功能描述**: 分析通訊性能指標。

**詳細需求**:

- **響應時間分析**
  - 平均響應時間
  - 最大/最小響應時間
  - 響應時間分布圖（直方圖）
  - 響應時間趨勢圖

- **吞吐量分析**
  - 每秒操作數（OPS）
  - 數據吞吐量（位元組/秒）
  - 吞吐量趨勢圖
  - 峰值吞吐量識別

- **延遲分析**
  - 網路延遲（RTT）
  - 處理延遲（設備響應時間）
  - 延遲分布分析
  - 延遲異常檢測

- **性能瓶頸識別**
  - 自動識別性能瓶頸
  - 瓶頸原因分析
  - 優化建議生成

#### 5.1.5 診斷工具

**功能描述**: 提供問題診斷與優化建議。

**詳細需求**:

- **通訊異常檢測**
  - 自動標記異常封包
  - 異常模式識別（重複錯誤、間歇性錯誤）
  - 異常統計與報告

- **協議合規性檢查**
  - 檢查封包是否符合協議規範
  - 違規項目列表
  - 合規性評分

- **優化建議**
  - 基於分析結果生成優化建議
  - 建議分類（性能優化、錯誤修復、配置優化）
  - 建議優先級標示

- **問題診斷報告**
  - 自動生成診斷報告
  - 報告包含：問題摘要、詳細分析、優化建議
  - 報告格式：HTML、PDF（可選）

### 5.2 進階功能

- **封包重放**
  - 選擇歷史封包序列
  - 重現通訊過程
  - 重放速度控制
  - 重放結果對比

- **協議模擬**
  - 模擬設備響應
  - 自定義響應規則
  - 模擬異常情況（錯誤響應、超時）
  - 用於測試與開發

- **自定義解析規則**
  - 擴展協議支援
  - 自定義欄位解析
  - 自定義過濾規則
  - 規則匯入/匯出

- **分析報告生成**
  - 生成詳細分析報告（PDF、HTML）
  - 報告包含：統計數據、圖表、診斷結果、建議
  - 報告模板自定義（可選）

### 5.3 技術實現要點

- **封包捕獲**: 在傳輸層攔截封包（需要後端支援）
- **數據存儲**: IndexedDB 存儲封包數據
- **解析引擎**: 協議解析器（可擴展架構）
- **視覺化**: 使用 D3.js 或類似庫實現時序圖
- **性能優化**: 虛擬滾動、數據採樣、增量更新

4. **協議分析器** - 深度診斷，適合進階用戶

#### Phase 1: 模板管理（預計 2-3 週）

- 週 1: 模板 CRUD、分類管理
- 週 2: 模板內容定義、快速應用
- 週 3: 進階功能（版本管理、分享）

- 週 4: 進階功能（回放、對比）

#### Phase 3: 對比模式（預計 3-4 週）

- 週 1: 多連線管理、同步操作
- 週 2: 對比視圖、圖表實現
- 週 3: 對比分析、報告生成
- 週 4: 進階功能（模板、自動化）

- 週 3: 通訊分析、性能分析
- 週 4: 診斷工具、報告生成
- 週 5: 進階功能（重放、模擬）

### 技術債務與注意事項

- **數據存儲**: 需要統一規劃數據存儲方案（LocalStorage vs IndexedDB）
- **狀態管理**: 考慮引入狀態管理庫（如 Zustand）管理複雜狀態
- **性能優化**: 大量數據場景需要虛擬滾動、分頁、索引優化
- **後端支援**: 協議分析器需要後端封包捕獲支援
- **UI/UX**: 保持與現有測試工具一致的設計風格

### 里程碑

- **M1**: 模板管理 MVP（基本 CRUD + 快速應用）
- **M2**: 測試歷史 MVP（記錄列表 + 詳情 + 基本統計）
- **M3**: 對比模式 MVP（多連線 + 同步操作 + 基本對比）
- **M4**: 協議分析器 MVP（封包捕獲 + 基本解析 + 統計）

### B. API 端點規劃

#### 模板管理 API

- `GET /api/v1/templates` - 獲取模板列表
- `POST /api/v1/templates` - 創建模板
- `GET /api/v1/templates/:id` - 獲取模板詳情
- `PUT /api/v1/templates/:id` - 更新模板
- `DELETE /api/v1/templates/:id` - 刪除模板
- `POST /api/v1/templates/import` - 匯入模板
- `GET /api/v1/templates/:id/export` - 匯出模板

#### 測試歷史 API

- `GET /api/v1/history` - 獲取歷史記錄列表
- `GET /api/v1/history/:id` - 獲取記錄詳情
- `DELETE /api/v1/history/:id` - 刪除記錄
- `POST /api/v1/history/export` - 匯出記錄
- `GET /api/v1/history/statistics` - 獲取統計數據

#### 對比模式 API

- `POST /api/v1/compare/connections` - 創建對比連線組
- `POST /api/v1/compare/execute` - 執行同步操作
- `GET /api/v1/compare/results` - 獲取對比結果
- `GET /api/v1/compare/report` - 生成對比報告

#### 協議分析器 API

- `POST /api/v1/analyzer/capture/start` - 啟動封包捕獲
- `POST /api/v1/analyzer/capture/stop` - 停止封包捕獲
- `GET /api/v1/analyzer/packets` - 獲取封包列表
- `GET /api/v1/analyzer/packets/:id` - 獲取封包詳情
- `GET /api/v1/analyzer/statistics` - 獲取統計數據
- `GET /api/v1/analyzer/report` - 生成分析報告
