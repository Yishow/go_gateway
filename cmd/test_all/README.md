# 完整協議測試程序

此程序用於測試所有協議的 TCP 和 RTU 連接功能。

## 支援的協議

- **Modbus**: TCP (127.0.0.1:502) 和 RTU (COM4/9600/8,N,1)
- **MC Protocol**: TCP (127.0.0.1:6000) 和 RTU (COM4/9600/7,E,2)
- **Fatek**: TCP (127.0.0.1:2000) 和 RTU (COM4/9600/7,E,2)

## 編譯

```bash
go build -o test_all.exe ./cmd/test_all
```

## 執行

```bash
./test_all.exe
```

或直接執行：

```bash
go run ./cmd/test_all
```

## 測試內容

### Modbus TCP

- 讀取保持暫存器 (0-9)
- 寫入單個暫存器 (位址 0，值 12345)
- 驗證寫入結果
- 讀取線圈 (0-9)

### Modbus RTU

- 讀取保持暫存器 (0-9)
- 寫入單個暫存器 (位址 0，值 12345)
- 讀取線圈 (0-9)

### MC Protocol TCP

- 讀取字組設備 D (0-9)
- 寫入字組設備 D (位址 0，值 [100, 200, 300])
- 驗證寫入結果
- 讀取位元設備 M (0-9)

### MC Protocol RTU

- 讀取字組設備 D (0-9)
- 寫入字組設備 D (位址 0，值 [100, 200, 300])
- 讀取位元設備 M (0-9)

### Fatek TCP

- 讀取暫存器 D (0-9)
- 寫入暫存器 D (位址 0，值 [100, 200, 300])
- 驗證寫入結果
- 讀取狀態 X (0-9)

### Fatek RTU

- 讀取暫存器 D (0-9)
- 寫入暫存器 D (位址 0，值 [100, 200, 300])
- 讀取狀態 X (0-9)

## 測試報告

程序執行完成後會顯示：

- 每個測試的狀態（通過/失敗）
- 測試耗時
- 總計、通過和失敗的測試數量

## 注意事項

1. 確保本地端有對應的伺服器運行
2. 確保串列埠 COM4 可用（RTU 測試）
3. 確保串列埠參數與 PLC 設定一致
4. 如果某個測試失敗，程序會繼續執行其他測試
5. 如果有任何測試失敗，程序會以退出碼 1 結束

## 協議補充說明

- **MC Protocol**：`device` 名稱大小寫不敏感（例如 `d` 等同 `D`）。
- **Fatek**：支援的 `symbol` 擴充包含 `DR/DD/DF` 與 `WX/WY/WM/WS/WT/WC`。
